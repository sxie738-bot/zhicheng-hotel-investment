# 致城酒店投资测算系统

一个专业的多用户酒店投资项目测算工具，支持客资协同录入、认领管理、智能测算、PDF导出。

## 功能特性

- **多人协同**：团队成员可同时录入客资，系统自动同步
- **客资认领**：谁用了客资可以自主认领，避免重复跟进
- **智能测算**：基于 PDF 中的完整三季模型计算，输出稳健/保守两套预测
- **投资决策**：自动给出「建议投资/谨慎投资/不建议投资」建议
- **PDF 导出**：一键生成专业测算报告，支持打印
- **桌面使用**：可保存到桌面，双击启动，局域网内多人访问

## 使用说明

### 1. 启动服务
启动后终端会显示：
```
本机访问: http://localhost:8088
局域网访问: http://192.168.x.x:8088
```

### 2. 首次使用
- 打开浏览器访问显示的地址
- 输入您的名字（用于识别录入人和认领人）
- 开始使用

### 3. 客资管理
- **录入客资**：点击「+ 录入客资」填写酒店信息
- **认领客资**：看到别人录入的客资可点击「认领」
- **状态管理**：待处理 → 已认领 → 已测算

### 4. 投资测算
1. 切换到「投资测算」页
2. （可选）关联一个客资，自动填充基础信息
3. 填写租金、三季收入、成本参数
4. 点击「开始测算」
5. 查看结果，可导出 PDF 报告

### 5. 多人使用
- 将局域网地址（如 `http://192.168.1.100:8088`）发给同事
- 所有人访问同一地址，数据实时同步
- 各自录入客资，互不干扰

## 测算逻辑

系统完全复现 PDF 中的专业酒店投资测算模型：

### 租金测算
```
年固定租金 = 总面积 × (平方月租金 + 物业费) × 12
年浮动租金 = 扣点基数 × 扣点率%
年总租金 = 年固定租金 + 年浮动租金
```

### 三季收入模型
```
季度收入 = 月份数 × 30 × 客房数 × ADR × OCC%
全年收入(稳健) = 旺季+平季+淡季收入
全年收入(保守) = 全年收入(稳健) × 折扣率%
```

### 成本与决策
```
间夜成本 = 年总租金 / 间夜数 + 边际成本/间夜 + 人工成本/间夜
GOP毛利 = 全年收入 - 租金成本 - 运营成本
年化回报 = 项目介入预算 ÷ 经营方年纯利
```

### 投资建议规则
- 年化回报 < 2.5年 且 GOP率 > 30% → **建议投资**
- 年化回报 < 5年 且 GOP率 > 15% → **谨慎投资**
- 其他 → **不建议投资**

## 常见问题

### Q1: 如何修改端口？
编辑 `app.py` 第 15 行 `PORT = 8088` 改为其他端口。

### Q2: 数据保存在哪里？
`data/zhicheng.db` SQLite 文件，可备份或迁移。

### Q3: 如何重置数据？
删除 `data/` 目录，重启服务。

### Q4: 支持多少用户？
理论上无限制，SQLite 可支持数百并发。

### Q5: 如何部署到服务器？
将整个文件夹上传到服务器，运行 `python app.py` 即可。

## 开发说明
